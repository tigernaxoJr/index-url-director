後端不跑 AI 的
代理卸載式前端架構

打造 AI 產品，卻不必在後端扛 GPU 與巨額推論成本。網頁應用只是一份靜態的協議皮囊（Protocol Shell）； 使用者手上既有的 Coding Agent（Claude Code、Codex、Cursor、Pi 等）才是負責推理與執行的心臟引擎。

Core Architecture

皮囊與心臟：零推論協同機制

前端從不執行模型，而是將規格與 Schema 寫入本機資料夾；使用者的 Agent 讀取規格、完成工作並寫回產物。

Shell 皮囊

靜態 Web UI

純靜態前端，託管於 CDN / GitHub Pages。不設後端伺服器，不儲存任何使用者資料。

  • ✓ 視覺化工作台與編輯器
  • ✓ JSON Schema 契約即時校驗
  • ✓ 零後端維運與零邊際算力成本
Bus · SSOT 匯流排

本機資料夾

透過標準 File System Access API 授權，本機檔案系統即為唯一真理來源。

  • ✓ *.project.json 專案設定
  • ✓ *.activity.json Agent 即時動態
  • ✓ 產物檔案（PDF, MP4, Markdown, SVG）
Heart 心臟 · 引擎

使用者的 Coding Agent

由使用者現有的 Agent 驅動執行（Claude Code、Cursor、Windsurf 或本機開源模型）。

  • ✓ 深度邏輯推理與結構化生成
  • ✓ 調用本機工具 (Playwright, FFmpeg, TTS)
  • ✓ 推論費自備 (BYOA)，服務商零負擔

Guiding Rules

四大核心原則

符合以下四點，才算真正的 AOFA 架構。

01

零推論控制層

應用層不跑模型、不做重度運算。無論千人還是百萬人造訪，服務商的邊際算力成本始終趨近於零。

02

Schema 即合約

UI 與 Agent 透過開放標準的 JSON Schema 協作，而非封閉私有 API。前端嚴格驗證 Agent 產出的每一項內容。

03

檔案系統即匯流排

本機資料夾是唯一真理來源（SSOT）。UI 以輕量檔案中繼資料特徵碼偵測變更，維持極簡且堅不可摧的狀態同步。

04

本地優先·邊界自決

使用者資料完全不經服務商伺服器。唯一的第三方是使用者自選的 LLM 方案；若改用 Ollama 等本機模型則完全離線。

Paradigm Shift

雲端 GenAI SaaS vs. AOFA

AOFA 並未讓推論變免費，而是將算力移至使用者已付費的 Agent 訂閱或自建硬體上，解開商業模式的死結。

評比維度 傳統雲端 GenAI SaaS AOFA 代理卸載架構
主機託管 GPU 主機、向量資料庫、高昂流量費 CDN 上的純靜態檔案（GitHub Pages）
推論算力成本 服務商自行吸收墊付，再以訂閱制轉嫁 使用者自備 Agent（BYOA）或本機模型
使用者資料隱私 商業機密與隱私上傳並儲存於廠商雲端 100% 留在使用者本機磁碟，完全不出境
產物透明可控性 黑盒產物，不滿意只能重新碰運氣生成 透明標準檔案（MD, SVG, Vue, PDF），隨時可手改
系統運維負擔 7x24 小時後端集群監控、斷線與負載維護 零後端伺服器，無需任何維運人員
Progressive Adoption

三種漸進式通訊模式

從極簡零設定到多團隊協同，依應用複雜度彈性選擇。

A

模式 A：純工作台模式

代表實作：Slide Studio

檔案驅動。UI 輪詢檔案特徵碼，並提供指令讓使用者貼給 Agent 執行。使用者不需要安裝任何常駐程式或額外環境。

B

模式 B：伴侶增強模式

代表實作：Video Studio

在 127.0.0.1 執行微型 WebSocket 伴侶，以 Origin 檢查與 Token 安全配對，在網頁上提供一鍵觸發指令重跑與主動推播。

C

模式 C：具後端混合架構

企業/團隊擴充模式

輕量雲端控制平面只負責帳號認證、權限管理與計費；所有重度運算與敏感檔案資料始終留在使用者本機（自備 Agent，BYOA）。
